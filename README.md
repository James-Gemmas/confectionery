# Кондитерская Sweet Date

Веб-приложение для заказа тортов с доставкой к определённой дате.

## Как работает сайт

### Для обычного пользователя

1. Регистрация или вход по email и паролю.
2. Просмотр каталога тортов: название, описание, цена, вес, вид торта, фотография.
3. Добавление тортов в корзину.
4. Переход в корзину, выбор даты доставки, оформление заказа.
5. Просмотр истории своих заказов и их статусов (в обработке, оплачен, доставлен).

### Для администратора

1. Вход в панель управления по адресу /admin.
   Логин: admin@mail.ru, пароль: 12345678.
2. Управление товарами: добавление, редактирование, удаление, загрузка фотографий.
3. Управление заказами: просмотр всех заказов, изменение статуса заказа.
4. Просмотр списка пользователей.

## Технологии

- Ruby on Rails
- База данных SQLite (разработка) / PostgreSQL (продакшн)
- ActiveStorage для загрузки картинок
- Devise для аутентификации
- ActiveAdmin для панели администратора

## Запуск проекта

1. Склонировать репозиторий.
2. Выполнить bundle install.
3. Выполнить rails db:create db:migrate.
4. Запустить rails server.
5. Открыть localhost:3000.

## Наполнение базы данных товарами

Выполнить rails db:seed. В файле seeds.rb содержатся 30 тортов с характеристиками (название, описание, цена, вес, вид торта). Фотографии добавляются через админку вручную.

## Примечание

Все данные о товарах (вес, вид торта, картинки) видны обычным пользователям на главной странице.
